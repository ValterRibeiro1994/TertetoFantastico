# **Projeto PetShop**

## *Recriar o projeto desenvolvido na aula de desenvolvimento de sistemas com o professor Marcelo Della Torre.*

    O projeto pedido envolve a criação de pequenos Crud para um Pet shop, onde deve ser armazenados os tutores e seus pets
    os serviços realizados e possiveis consultas, no momento o objetivo é apenas recriar o projeto que está localizado no
    repositorio TertetoFantastico > Desenvolvimento-de-sistemas > AppPetShop, o projeto realizado em C# com windows form
    foi realizado pelo Trio Lucas Ubraz, Felipe Rodrigo e Valter Tertuliano assim como todas as outras atividades do 
    repositorio.

## *Versão Web*

    A ideia principal é recriar o projeto para uma versão Web do mesmo sistema, por enquanto não foi pensado requistos de 
    segurança e autenticação, sendo possivel uma implementação desses requisitos, o projeto será iniciado buscando criar um
    painel administrativo inicial contendo os formularios de entrada e as tabelas para saida de consulta conforme realizado
    no projeto base.

## *Desafios do projeto*

    Planejar como o projeto será desenvolvido na sua versão web, como organizar as etapas de trabalho, e qual método vamos
    usar para o desenvolvimento do sistema como um todo.
