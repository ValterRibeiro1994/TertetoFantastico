## **Projeto PetShop**

# Quem vai usar o sistema ?
    O sistema vai ter o Dono como administrador, os visitantes da página, os clientes da loja e os
    funcionarios reponsavel pelo atendimento ao cliente.

# Quais Problemas o sistema deve resolver ?
- 1° Problema 
    O dono deseja ter um sistema web que permita aos seus clientes realizar o agendamento dos serviços do pet shop(banho e tosa), esse mesmo sistema deve exibir os produtos da loja
    permitindo que o cliente realize as compras online, a loja oferece o serviço de entrega.
